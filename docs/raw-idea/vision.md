I want to create a web app, and then maybe later a mobile app as well, but the core purpose of this thing is your medical wallet. A user can go to a doctor, and the doctor will write a prescription. The user can just take a picture and upload it, or the user can write manually what medicine the user took and how the prescription is available.

For example, I will just tell you one scenario, one use case: I go to a doctor, and the doctor writes a prescription. I upload that prescription. That prescription is recorded on that date and time. I will not eat all the tablets some times, and some times I will eat all. I can go any time and modify that I took this much medicine, but the original value will still exist. The prescribed medicine and consumed column will be there. If there is an injection or anything, even if some day I might take aspirin, I will just make an entry. This medical data will be recorded.

Whenever a person goes to any country, for example, a person goes to Russia, the user can export his data into the Russian medical file format system. If the user goes to the US, for example, and the US follows HL7 format, the user can export HL7 format 7.1 to whatever is available for the EMR system.

Apart from taking pictures, the user can also create a manual prescription, like a new entry or a prescription of medicine entry or something, with a button. When the user clicks, they will see the options of medicines. We might have auto-compute, but I don't know if this is possible. Is there any API that gives us all the medicine data? It is not necessary, so it can be a suggested name. Once the user enters the medicine name, there is an option: is it a pill, or is it a liquid like a serum, or is it an injection? If there is any other type, the user can select from that time what time it is. After that time, there are circles, consumption things like how much you are going to consume and how you treat the consumption. All this thing is like a medical wallet.
